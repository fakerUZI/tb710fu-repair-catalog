# TB710FU 完整虚拟键盘与安卓应用手势

适用于 TB710FU、Ubuntu 26.04 ARM64、GNOME Shell 50 Wayland。需要已安装并配置的 Fcitx5、WowType、`tb-fcitx5.service` 和 Droidloom。此条目提供整套桌面集成，在同一次操作中应用键盘与安卓手势。

- **虚拟键盘**包括输入策略、快捷键和预编辑、键盘开关、WowType 触摸适配、主题与语音浮条、Kimpanel 全部模块及本地化资源，以及退格回退扩展。全扩展 text 页的逗号和句号跟随 Fcitx5 中文或英文输入。两个符号页包含 Tab、方向键、Shift 换页、中英文标点、括号和比较符号。
- **安卓手势**包括第 13 版的窗口默认最大化、焦点阴影、顶栏窗口菜单、底部白条、最近任务，以及左右两侧返回。键盘打开时暂停冲突手势。
- **输入法会话**包括显示环境就绪后再启动 Fcitx5 的脚本和用户服务配置。保留现有输入法列表、用户词库和其他自定义配置。

Git 中的 `source/` 可逐文件审查。应用需要同一个目录条目的 Bash 入口和 `attachments/` 中的全部附件。安装器会校验包内清单，在本地生成 Kimpanel 的 GNOME schema。

## 使用与回退

从修复助手运行完整条目。手动运行时，进入贡献目录并执行：

```bash
bash script.sh
TB710FU_FIX_ACTION=apply bash script.sh
TB710FU_FIX_ACTION=rollback bash script.sh
```

第一条执行依赖和附件检查。应用或回退后请保存工作，再注销并重新登录 GNOME。当前会话在扩展切换后可能暂时失去软键盘或手势。系统级程序及安卓应用数据保留。回退快照留在本机的 `$XDG_STATE_HOME/tb710fu-keyboard-android-gestures/`，默认位于 `~/.local/state/`。若受影响的文件在应用后又被改过，自动回退会停下来。

此整套条目覆盖候选区、退格和安卓窗口导航的桌面集成。请勿在同一账户上交替应用旧的独立候选区或安卓手势条目。候选区依赖 Fcitx5 / WowType / Kimpanel。快捷栏包含本地剪贴板历史和截图入口，按用户操作使用现有 GNOME 会话数据。

## 验证

配套组件来自 TB710FU 平板的 GNOME Shell 50.1。中英文实时标点在平板终端实测来回切换并点按输入，窗口和手势扩展与平板正在使用的第 13 版文件逐一比对。合并入口使用隔离目录验证应用、重复应用、失败恢复和手动回退，并在平板运行只读检查。修复助手实际应用后重新登录的端到端验证仍待完成。
