# USB-C／DisplayPort 双屏自动切换

TB710FU 在内屏 144Hz 下接 DP 外屏时，可能无法显示桌面或出现灰屏。此条目将可用的显示模式保存给 GNOME。接上这台显示器时，内屏为 3200×2000、120Hz，外屏保持当前分辨率并选择约 60Hz。拔线后，GNOME 会载入此账号原先保存的单屏模式，例如 144Hz。

## 适用与操作

面向 TB710FU 的 Ubuntu GNOME Wayland 桌面。按本机显示器实际提供的模式配置，原始实测使用 1118 内核。需要系统 Python 3、PyGObject（`python3-gi`）及当前活动的本地图形会话。用普通账号执行。

1. 先断开 DP。在 GNOME 显示设置中确认已经保存你希望拔线后恢复的单屏刷新率。
2. 登录后接上一台原生 DP 显示器，显示设置选“加入显示”。脚本保留当前外屏分辨率、缩放、方向和摆放。若外屏当前分辨率没有约 60Hz 模式，先在 GNOME 选择一个支持该刷新率的分辨率。
3. 从修复助手下载并运行条目。出现 GNOME 的确认窗口时，检查两块屏的画面，再点击“保留更改”。若画面异常，等待 GNOME 自动恢复。保存的配置按当前账号和显示器配对。
4. 拔线、再插回同一台显示器，分别检查单屏与双屏的刷新率。

默认动作 `apply`。也可在本机以 `TB710FU_FIX_ACTION=check` 运行只读检查，支持仅接内屏的状态。应用配置时会短暂切换两块屏的时序。此条目使用 GNOME 保存设置，不安装常驻服务或内核模块。

## 回退

脚本需要保存新配置时，会把之前的 `monitors.xml` 保存在当前账号私有状态目录 `${XDG_STATE_HOME:-$HOME/.local/state}/tb710fu-dp-refresh-profiles/rollback.json`。该文件包含本机显示器配对信息，请留在本机。对已有正确保存配置的设备重复运行，无需重写配置或新建回退记录。

以 `TB710FU_FIX_ACTION=rollback` 运行，只有当前文件与条目确认保存的版本完全一致时才恢复原文件；恢复后注销、重新登录使其生效。若后续修改了显示配置、上次确认未完整结束或本条目没有回退记录，可直接在 GNOME 显示设置中重选双屏模式。测试中的异常退出会保留有用的私有备份。

## 验证范围

- TB710FU 实测过 GNOME 原生保存内屏单屏 144Hz、双屏内屏 120Hz 与外屏 2560×1440、59.951Hz，拔插同一台显示器后两套配置会自动切换。
- 投稿脚本的只读入口已在上述内核的实际平板上检查保存的配置。写入、确认超时、重复执行、冲突和回退由隔离测试覆盖。
- 此条目提供可用的双屏配置路径。144Hz 双屏内核修复及其他显示器与转接器需分别验证。
