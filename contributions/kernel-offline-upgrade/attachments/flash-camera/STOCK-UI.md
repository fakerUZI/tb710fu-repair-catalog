# 原厂 ZuiCamera 风格的 Ubuntu 拍照页

参考的是这台 TB710FU 自带的 Android 相机，从当前 Android 基础 `system_a` 以只读映射提取：

- 包名：`com.zui.camera`
- 版本：`18.0.1.251216192500`，versionCode `180019999`
- APK SHA256：`7da461a8b8eb4a707420ac7916557ddfd716056a022101ffa1b46d04ba43cf0a`

静态解析了其清单、资源表和 338 个布局资源，参考 `camera`、`sticky_bottom_capture_layout`、`bottom_bar_contents`、`mode_options`、`zoom_layout` 的结构：横屏右侧拍摄栏、白色圆形快门、前后切换、圆形相册缩略图、左侧工具及黄色选中状态（原资源颜色 `#E8BC05`）。这属于按原厂静态资源重建的 Ubuntu 原生界面；没有启动 Android 做逐像素运行截图对照。

原 APK、原厂图标/资源文件、Android 原生库和解码目录保持私有，不随修复包发布。新界面的图标是独立绘制的 SVG，界面使用 GTK4/CSS；拍摄继续使用现有 libcamera/GStreamer 与三路传感器。原厂 Android 的 HDR、美颜、人像算法未移植，也未用无效按钮充当已实现功能。

## 页面操作

- 横屏右侧为切换前后摄、圆形快门和相册缩略图；竖屏自动排列到底部。
- “拍照”使用主后摄或当前前摄，“微距”切到第二后摄；切换图标记住最近使用的后摄。
- 1× 按钮循环数字变焦，支持双指缩放及放大后拖动。真实保存尺寸在设置里显示。
- 轻触画面显示对焦框并触发主摄对焦；设置里保留拍照前自动对焦、手动对焦及预览分辨率。
- 补光使用现有受限 D-Bus 手电筒，实际为常亮灯，不是相机同步闪光。前摄禁用此按钮；切前摄或退出时关闭本应用开启的灯，并保留原有 60 秒限制。
- 九宫格、3/10 秒倒计时均可操作；切镜头或退出会取消未完成的倒计时。
- 快门等待期间显示进度，拍摄完成后可点击缩略图查看照片。Esc/左上返回可退出。

## 安装与恢复

沿用当前唯一内核条目的 `flash-install` 或 `camera-install` 动作；不添加新的内核升级入口。

已有完整配套、且变动仅涉及已管理的相机应用/桌面入口时，安装器使用界面原子更新路径：先核对当前文件和原始快照，记录上一修订哈希，更新界面和持久化载荷。**六项现有相机/手电筒服务保持运行。** 若写入失败，则恢复更新前的界面和安装状态。首次安装或包含硬件变更时仍使用原完整流程。

原始快照和现有全配套回退入口继续保留；`camera-rollback` 的含义仍是恢复首次快照及原 Ubuntu libcamera，不是仅回退本次页面。内核镜像、日期命名、七个内核分片、传感器模块、供电和固件分区均不因页面更新而改变。
