# Ubuntu 内核 1118 升级到 1124

适用于小新 Pad Pro GT（TB710FU）Ubuntu 单系统。修复助手中先选「Ubuntu 内核升级：1118 → 1124（可选）」，下载并单独运行。完成后将电脑可用的回退镜像保存好，手动重启。用 `uname -r` 确认显示 `7.2.6-tb710fu-20261124` 后，即可按需选择单独的 U-Boot 条目。只升级内核的设备继续使用 kShim 和原来的 `arch` 分区。

## 适用条件

- 正在运行 `7.2.6-tb710fu-20261118`，根文件系统为 GPT 标签 `arch` 的 ext4，A 槽已成功启动。支持原公开 1118 boot 和 BOOTFIX / SLOT-FIX 的 1118 boot。脚本会核对机型、运行内核配置、当前 GPT、A 槽状态及源 boot 的完整 SHA-256。
- 1124 将磁吸键盘驱动编入内核，并安装相同版本的模块。已有相机、对焦、微距和补光灯适配会使用对应的 1124 模块。不受支持的启动镜像或无法匹配的配套文件会停止安装，并在日志说明原因。
- 预检只读核对 ABL、XBL、XBL config 的 A/B 分区及 dtbo_a、vendor_boot_a。这 8 个分区保留本机固件，内容与参考机不同只输出分区名。分区缺失、标签指向错误或读取失败仍会停止。此前停在「固件不匹配：abl_a」的用户可更新仓库并重新下载本条目，先运行只读检查。关闭助手后，从桌面终端运行 `TB710FU_FIX_ACTION=check tb710fu-repair-assistant`，选中本项并点运行。确认检查通过后，关闭助手并从应用菜单正常打开，再单独安装。
- 安装会写入 `boot_a`。保持供电，并准备电脑端恢复方式。附件约 28 MiB；重建、备份和安装期间建议根分区预留 1 GiB。脚本保留 1118 模块以及原设备的备份。

## 检查和回退

`TB710FU_FIX_ACTION=check` 检查机型、版本、启动分区、固件和 GPT。单独运行安装时，助手使用 `apply`。脚本从本机旧 boot 生成已验证的 1124 镜像，先安装模块和配套文件，再写启动分区并完整回读。成功后自行保存工作并重启。原启动镜像保存在 `/var/backups/tb710fu-kernel-1118-to-1124/boot_a.img`，建议重启前复制到电脑。

如需回退，使用 `TB710FU_FIX_ACTION=rollback` 运行同一条目。脚本验证备份和当前启动状态，恢复本机原有的 1118 启动镜像和配套脚本；重启后运行原内核。1124 的版本目录保留，供当前会话和后续重试使用。已经切换 U-Boot 的设备，应先从 U-Boot 条目回退至 1124 kShim，再回退内核。

## 验证范围

已在 ARM64 Ubuntu 隔离环境，用公开 BOOTFIX 根文件系统中的实际模块和脚本演练安装、回退和再次安装。两种公开 1118 启动镜像均重建到同一 SHA-256：`3f3694ab3f18e656b1117fdaa399bbdfac855b0dba9941b0d4c420d88525382a`。这个 1124 镜像在开发平板上运行过。新助手条目的真实分区写入仍待另一台 1118 设备验证。
