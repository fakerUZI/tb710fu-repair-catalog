# TB710FU 磁吸键盘实机测试

此条目供带联想原装三触点磁吸键盘、运行 `7.2.6-tb710fu-20261118` 内核的平板试用。先保存工作，吸上键盘，再在修复助手「更新仓库」后单独下载并运行「磁吸键盘实机测试（60 秒）」。有条件时可以保留 USB 连接以方便查看系统状态。

测试窗口内，请打开空白文本编辑器敲几个键，移动触控板并点击，再拔下和吸回键盘各一次。请保留修复助手的运行记录，并记录按键、触控板、拔插和音量键的实际表现。测试结束时会检查是否观察到键盘和触控板设备。

脚本在内存应用临时设备树，通过系统已有的 RPMh 驱动启用原厂设备树对应的 PM8550B 电源轨，并短暂重绑音量键和合盖检测。测试退出时按逆序卸载，重新绑定原按键驱动并核对设备树。测试期间可能发生按键暂时无响应或系统卡住。系统若卡住，重启会回到正常启动流程，测试模块没有开机服务。

使用 `TB710FU_FIX_ACTION=check` 可以只检查当前内核、设备树、供电配置和模块。匹配已核对设备树的平板使用随包 DTBO，其他兼容布局需要 Ubuntu 的 `device-tree-compiler`。

两个模块由当前适配内核的配置和 `Module.symvers` 本地重编译，源码见条目目录中的 `source/`。键盘驱动来源为 `kisodev/android_kernel_lenovo_sm8650` 的 `5cd19e48fb9578d781c931de085f5b0d03cd6cde`，经社区投稿移植后调整了 UART、供电和退出流程。已通过设备树合并、模块构建、隔离退出/回退及平板只读检查。按键、触控板、拔插和挂起唤醒仍需要带键盘实测。
