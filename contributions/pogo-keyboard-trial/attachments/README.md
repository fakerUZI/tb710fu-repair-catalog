# TB710FU 手写笔、磁吸键盘与触控板联合测试版

适用于小新 Pad Pro GT（TB710FU）和 `7.2.6-tb710fu-20261118` 内核，包含原装三触点磁吸键盘、触控板和手写笔。已为公开的 20261118 原版触控模块和双击唤醒修复版分别编译手写笔模块。

已在使用双击唤醒版触控模块的 TB710FU 上验证联合安装、重启、手写笔扫描及坐标分辨率、磁吸键盘 UART 和机身按键驱动。原装配件的书写、压感、打字、触控板和拔插仍待实际操作验证。

此测试包单独安装。键盘服务在安装后启动，手写笔随下一次开机加载。手写笔模块默认开启笔扫描，并为 GNOME/libinput 提供适合 11.1 英寸屏幕的坐标分辨率。若旧键盘脚本失败后机身音量＋失效，先重启再安装。

支持键盘、触控板和拔插。顶排默认执行音量、麦克风静音、亮度和截图。单按 ★ 切换 F 键模式，再按一次切回。在 GNOME Wayland 中安装时，会为当前登录账号添加全屏和左侧平铺快捷键，保留原有绑定。其他账号可以在自己的 GNOME 会话里重新运行安装项来添加快捷键。

安装时会检查内核、设备树和 PM8550B 供电轨。设备树覆盖只启用键盘 UART。GPIO81 已由机身按键驱动管理时，键盘通过现有霍尔开关输入读取状态。服务启动和停止均保留机身按键驱动的绑定。手写笔安装器按当前触控模块的路径和 SHA-256 选择匹配的构建，并保存一份原触控模块供回退。

如需停止或重新启动服务，可执行：

```bash
sudo systemctl stop tb710fu-pogo.service
sudo systemctl start tb710fu-pogo.service
```

使用 `TB710FU_FIX_ACTION=check` 可做只读检查。使用 `TB710FU_FIX_ACTION=rollback` 可恢复原触控模块，重启后生效。联合包首次装入的键盘服务和快捷键也会一并移除，安装前已有的键盘修复会保留。脚本需要用 `TB710FU_ATTACHMENTS_DIR` 指定其附件目录。

启动失败时可在修复助手查看输出，或执行 `journalctl -u tb710fu-pogo.service -b --no-pager` 查看服务日志。键盘驱动源码在条目的 `source/`，基于 `kisodev/android_kernel_lenovo_sm8650` 的 `5cd19e48fb9578d781c931de085f5b0d03cd6cde` 及社区提交，经适配后针对当前内核重编译。
