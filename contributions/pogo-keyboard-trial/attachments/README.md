# TB710FU 磁吸键盘与触控板测试版

适用于小新 Pad Pro GT（TB710FU）、联想原装三触点磁吸键盘和 `7.2.6-tb710fu-20261118` 内核。本版已在平板上验证安装、UART 启动和机身按键驱动绑定。打字、触控板和拔插仍待使用原装键盘实测。

在修复助手点击「更新仓库」，选中「磁吸键盘与触控板（测试版）」，然后点击「下载 → 运行脚本」。此条目单独安装。安装成功后，键盘服务立即启动，并在下一次开机自动加载。旧版安装失败后如果机身音量＋失效，先重启平板恢复机身按键，再安装测试版。

支持键盘、触控板和拔插。顶排默认执行音量、麦克风静音、亮度和截图。单按 ★ 切换 F 键模式，再按一次切回。在 GNOME Wayland 中安装时，会为当前登录账号添加全屏和左侧平铺快捷键，保留原有绑定。其他账号可以在自己的 GNOME 会话里重新运行安装项来添加快捷键。

安装时会检查内核、设备树和 PM8550B 供电轨。设备树覆盖只启用键盘 UART。GPIO81 已由机身按键驱动管理时，键盘通过现有霍尔开关输入读取状态。服务启动和停止均保留机身按键驱动的绑定。没有连接键盘时也可以安装。正式运行默认关闭按键诊断日志。

如需停止或重新启动服务，可执行：

```bash
sudo systemctl stop tb710fu-pogo.service
sudo systemctl start tb710fu-pogo.service
```

使用修复脚本的 `TB710FU_FIX_ACTION=rollback` 可卸载服务和附件、移除开机加载，并恢复安装时添加的 GNOME 快捷键。使用 `TB710FU_FIX_ACTION=check` 可做只读检查。脚本需要用 `TB710FU_ATTACHMENTS_DIR` 指定其附件目录。

启动失败时可在修复助手查看输出，或执行 `journalctl -u tb710fu-pogo.service -b --no-pager` 查看服务日志。键盘驱动源码在条目的 `source/`，基于 `kisodev/android_kernel_lenovo_sm8650` 的 `5cd19e48fb9578d781c931de085f5b0d03cd6cde` 及社区提交，经适配后针对当前内核重编译。
