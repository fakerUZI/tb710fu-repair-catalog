# sudo 与软件安装的人脸验证

在修复助手中先安装「TB710FU 锁屏人脸解锁」，录入本账号人脸并启用。再单独安装本条目。重新打开「设置 → 隐私与安全 → 锁屏 → 人脸解锁」，在「用人脸识别验证系统密码」选择时段。首次安装默认关闭。

| 模式 | 何时重新选择验证方式 |
| --- | --- |
| 仅解锁后 | 每次锁屏再解锁后 |
| 仅开机 | 每次重新开机后 |
| 始终 | 更改模式或重新录入人脸后 |

第一次系统授权时输入 1 使用人脸，输入 2 使用密码。成功选择人脸后，有效期内每次需要验证都会重新调用前摄。弹窗或终端显示「正在识别人脸，请正视前置摄像头」，终端识别时另有临时桌面横幅。相机忙、超时、未匹配均回到密码。系统已有授权缓存时按原规则处理。

适用于 TB710FU、ARM64 Ubuntu 的 GNOME Wayland 和设置 1:50.3-0ubuntu0.2。识别使用现有 RGB 前摄和本机录入的特征，没有专门的活体检测。支持本机桌面终端 sudo、sudo -i 和 GNOME polkit 授权。平板上验证过连续 sudo，以及 PackageKit 实际安装、卸载测试包时的授权和提示。

安装保留已有的人脸资料、验证模式和兼容的设置入口。遇到其他定制设置版本会提示核对。可在设置里选「关闭」停用。修复助手以 TB710FU_FIX_ACTION=check 运行可做只读检查，使用 TB710FU_FIX_ACTION=rollback 可恢复当前账号的设置入口并卸载系统级 PAM 组件。卸载会影响这台平板上的所有账号。识别组件和模型由原「锁屏人脸解锁」条目管理。
