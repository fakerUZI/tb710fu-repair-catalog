# TB710FU 手电筒快捷设置入口修复

用于 TB710FU 的 GNOME Shell 50 Wayland。适合已安装含 `tb-torch@tb710fu` 的一键安装镜像，硬件加载服务和手电筒控制服务已运行，但右上角快捷设置缺少「手电筒」的情况。

修复会校验现有扩展文件，读取后台服务状态，把已安装的扩展目录设为普通桌面用户可读取的 0755，并为发起操作的用户启用磁贴。固件、内核、分区和相机同步闪光链路均在此条目范围之外。

从已登录的 GNOME 桌面使用修复助手，或在完整解包目录运行：

```bash
sudo env TB710FU_FIX_ACTION=check bash script.sh
sudo env TB710FU_FIX_ACTION=apply bash script.sh
sudo env TB710FU_FIX_ACTION=rollback bash script.sh
```

使用管理员权限调整系统扩展目录。应用或回退后保存工作，注销并重新登录。回退只恢复此用户此前的手电筒磁贴选择，目录的可读权限继续保留。若检查报后台服务未运行，需要查看对应服务的状态。

发布 ZIP 中的文件权限和默认扩展列表已从成品镜像核对。测试覆盖独立用户设置、重复应用、回退和写入失败。后台活动状态及 D-Bus 查询在平板只读检查。通过修复助手应用后重新登录并点亮磁贴仍需验证。
