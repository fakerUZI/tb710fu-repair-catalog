# BOOTFIX 安装后服务修复

在修复助手点「更新仓库」，下载并运行「BOOTFIX 安装后服务修复」。脚本通过管理员权限检查当前系统。它按现有文件和服务状态判断修复范围，适用于使用不同用户名、磁盘容量或启动镜像的 TB710FU。

- **Snap**：已初始化的 Snap 缺少通用型号或任务表时，补回这些结构，再启动 Snap 服务。已安装应用、账号信息和现有任务保留。Snap 缓存目录缺失时会重建。
- **anacron**：已安装 anacron 且缺少工作目录时，创建 `/var/spool/anacron`。
- **微距相机关机报错**：在已有微距脚本的相应流程中处理登录会话正在停止时的音频恢复错误。正常桌面会话的音频恢复失败仍会报告。

修复助手的「只读检查」只显示待处理项目。应用后可立即使用 Snap，微距变更会在下一次服务停止时生效。1124 的补光灯配套由内核升级负责安装。

被替换的文件只备份在本机 `/var/backups/tb710fu-startup-*/`。恢复 Snap 旧状态会重新引入启动故障，且可能覆盖后续 Snap 变更，备份供离线排查使用。
