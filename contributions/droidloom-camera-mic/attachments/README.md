# 安卓容器摄像头与麦克风修复

在 TB710FU 修复助手中下载并运行本项，可让 Droidloom 的安卓应用使用后置主摄、前摄、后置微距和内置麦克风。安装同时启用 Camera2 原生 JPEG 拍照补丁。安卓应用首次使用相机或麦克风时，照常按应用授权。

安装适用于各版本 Droidloom，可在更新容器后重新运行。助手使用已有的系统管理员授权，自动找到容器所属的桌面账号。安装前请保存安卓应用里的工作。正在运行的容器会自动重启，已停止的容器在下次启动时加载修复。

在 Droidloom 49 的真机测试中，安卓应用从三个镜头各取得 5 帧 640×480 图像。内置麦克风以 48 kHz 录音 4 秒，并录到扬声器发出的 1 kHz 测试音。JPEG 补丁通过 10 项缓冲区测试，安卓应用直接拍下并解码 JPEG 的真机结果仍待验证。

安装器为桌面账号配置 libcamera 与 PipeWire 服务，通过容器配置加载配套的安卓相机服务及 minigbm 库。涉及的旧文件及绑定在首次安装时备份。回退恢复这些文件与绑定，也会保留安装后新增的无关配置。

在条目目录执行 `bash script.sh check` 可检查依赖，`sudo bash script.sh rollback` 可回退。修复助手内运行时沿用助手的授权。
