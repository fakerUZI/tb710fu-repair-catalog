# USB-C 外接桌面控制

适用于联想 TB710FU 的 Ubuntu / GNOME Shell 50 桌面。使用支持视频输出的 USB-C 显示器或转接器，连接后在“设置 → 显示器”选择“扩展”。中文选词沿用平板已配置的 Fcitx5 / WowType。

在修复助手下载并运行本项。初次安装或升级后保存工作，注销并重新登录。点顶栏的触控板图标，选择“打开全屏键盘与触控板”。当外屏已经是主屏时，也可以点平板右上角的“外接桌面控制”。

- 内屏显示桌面键盘和触控板，外屏临时作为主屏。打开应用菜单、搜索、切换窗口时可继续操作。
- 单指移动或轻点，双指滚动。触控板下方提供左右键，抬手后外屏保留指针。点“全屏键盘”可收起触控板。
- 数字行、F1–F12、Tab、方向键和修饰键常驻。点修饰键再点目标键可输入组合键。“中 / 英”切换输入法；拼音候选显示在外屏输入位置，轻点数字行 1–5 选择对应的词。
- 点“退出”返回普通双屏；断开外屏、切换镜像或锁屏也会退出。普通平板模式继续使用原有触屏键盘。

脚本以当前桌面用户运行。默认命令行操作是只读检查，修复助手安装使用 apply。重复安装会核对已安装文件，相同版本可直接登记。rollback 停用该用户的扩展并保留文件，也可以在 GNOME“扩展”中手动停用。

版本 3 已在 TB710FU 和 27 英寸联想显示器上验证应用菜单、键盘、触控板与指针。已在外屏 GTK 输入框逐项验证数字 1–5 对应选词，并由使用者实机验收。功能依赖现有 USB-C 显示输出和 GNOME 50 的接口。本条目沿用当前显示模式。
