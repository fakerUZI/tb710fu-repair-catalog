# 磁吸键盘背折与顶栏屏幕键盘（测试版）

适用于 TB710FU 的 Ubuntu GNOME 50。在修复助手刷新目录，从此测试版的详情页单独安装或更新。装过上一版也可直接更新。保存工作后注销并重新登录 Ubuntu 桌面。

安装后将磁吸键盘背折一次，再展开一次，每个姿态停两秒。背折后用手指点 Ubuntu「设置」的搜索框，屏幕键盘应自动弹出。翻回打字位置，屏幕键盘应收起，再点搜索框也应保持收起。顶栏按钮在两种姿态下都可手动开关。另接可打字的 USB 或蓝牙键盘时仍屏蔽自动弹出。

本版安装 GNOME 输入策略、顶栏按钮补丁，以及仅匹配联想磁吸键盘的 udev 规则和 systemd 服务。服务只发布展开或背折状态，键盘移除后自动停止。首次接入后、收到第一个姿态事件前，桌面按可打字处理。修复助手回退后，再次注销登录即可恢复基础磁吸识别策略。

1118 原装键盘实测可上报背折和展开事件。在 1124 平板的隔离 GNOME 会话中，已用模拟输入设备验证两轮姿态切换、自动弹出和收起、顶栏开关及拔插。新版在 1118 原装键盘上的桌面表现仍待反馈。

## 采集显示与笔的反馈

可将附件 check-input.py 保存到桌面，在其所在目录运行 `sudo python3 check-input.py`。如果有笔，在能正常书写的刷新率和出现问题的刷新率各采一次。脚本汇总最近 10 分钟的显示 FIFO 欠载、触控固件复位和显示提交超时，并显示当前模式、系统合盖状态和驱动版本，在 12 秒内统计笔尖按下次数、正压力事件和峰值。若已接磁吸键盘，采样期间可背折和展开各一次，查看驱动是否报告禁用和启用。

黑屏或半屏的反馈请附上切换前后刷新率、是否在已解锁桌面、是否接 DP 外屏、黑的是哪一侧、熄屏再亮是否恢复。请优先提供实物照片。桌面截图只能显示合成画面。此次对照在只接内屏的 1124 平板上完成，模拟键盘和未接键盘时都观察到切换期间的 FIFO 欠载和触控固件恢复。面板候选驱动仍需独立验证。
