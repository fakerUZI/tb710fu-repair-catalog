# TB710FU 屏幕手势

在「设置 → 隐私与安全 → 锁屏 → 屏幕手势」加入 **双击亮屏** 和 **双击桌面空白处锁屏**，分别启用。双击亮屏用于系统仍在运行而内屏已熄灭的场景。进入系统挂起后请使用电源键。双击桌面空白处执行锁屏，点击图标、单击空白、右键、修饰键点击和拖选走各自的桌面操作。

## 适用范围

仅适用于联想 TB710FU、Ubuntu 26.04 ARM64、GNOME Wayland、设置 50.3（Ubuntu 包 1:50.3-0ubuntu0.2）、Ubuntu 桌面扩展 50.26.04.8ubuntu 和已核验的 7.2.6-tb710fu-20261118 触控与 60/120/144 Hz 显示模块组合。清单进一步检查匹配的驱动构建 ID、模块哈希、内核配置、活动槽位和固件。仅安装了同名内核的系统也可能拒绝执行。

## 安装、检查和回退

1. 在 TB710FU 修复助手更新仓库并下载本项。审阅脚本与风险后，从本机桌面以管理员权限运行。修复助手默认传入 `TB710FU_FIX_ACTION=apply`。安装只写 Ubuntu 文件系统，完成后保存工作并重启。
2. 两个开关默认关闭，安装后按需开启。禁用亮屏手势时恢复正常面板关屏供电。首次启动会核对模块和触控恢复，失败则恢复原文件并重启一次。
3. 可在修复助手以 `TB710FU_FIX_ACTION=check` 做只读检查，以 `TB710FU_FIX_ACTION=rollback` 执行回退，然后手动重启。也可在安装成功后运行 `sudo /usr/bin/python3 -I /var/backups/tb710fu-screen-gestures/install.py rollback`。回退会拒绝覆盖后来修改过的文件。此前单独安装的用户级设置覆盖由原安装方式管理。

## 验证与源码

本机确认手势命令移到面板关屏前后，可在保持正常 DCS Display Off / Sleep In 的情况下两次双击点亮锁屏。随后正式模块在本机重启加载，用户确认屏幕手势功能可用。最终桌面双击判定通过单击、连续双击、慢速点击、图标、右键、长按和关闭开关的测试，平板已重新加载对应 DING 进程和设置程序。最终投稿包的安装与回退使用隔离测试验证，未在另一台平板复测。

`screen-gestures-sources.tar.xz` 包含两份模块的源文件、Ubuntu 设置原始源包和补丁，以及构建说明。DING 的修改源码为附件 `desktopGrid.js`。
