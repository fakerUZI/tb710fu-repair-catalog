# TB710FU 屏幕手势

安装后保存工作并重启。打开应用菜单中的「屏幕手势」，或在兼容的定制 GNOME 设置中打开「隐私与安全 → 锁屏 → 屏幕手势」。两个开关互相独立。

- **双击亮屏**适用于系统仍在运行时的普通熄屏。启用后该状态会保留触控供电，可能增加待机消耗。
- **双击桌面空白处锁屏**支持连续点击或触摸空白桌面。单次点击、拖动选择、图标和窗口内点击沿用原行为。

安装复用已有双击亮屏 sysfs 接口。缺少接口时，只有与附件匹配的触控和面板驱动基线才会安装模块。安装只核对会用到的内核接口、桌面代码和附件。DING 和会话权限脚本只修改对应代码，保留其他位置的调整。只有在 GNOME 设置版本与附件匹配时才安装定制设置界面。应用菜单入口使用同一份用户偏好。

安装模块时，脚本为当前内核添加触控和面板模块的优先规则，并检查 `depmod` 选中的文件。若已安装含旧规则的版本，重新应用 05 会更新规则和索引。回退会恢复原规则，重启后按原优先级加载驱动。

`TB710FU_FIX_ACTION=check` 只读检查。需要重启后加载的新驱动首次验证失败时会自动恢复原文件并重启一次。手动回退可在修复助手以 `TB710FU_FIX_ACTION=rollback` 运行，或运行 `sudo /usr/bin/python3 -I /var/backups/tb710fu-screen-gestures/install.py rollback`，然后手动重启。遇到原相关代码已被其他补丁改动的提示，请保留当前版本并反馈报错和对应组件版本。

之前的 20261118 实机已验证双击唤醒和独立开关，最终桌面代码也通过单击、拖动和双击逻辑检查。对应内核补丁及桌面源码见附件 `screen-gestures-sources.tar.xz`。
