# 屏幕键盘右 Alt 语音输入（WowType）

在修复助手更新仓库，打开本条目并单独安装。保存工作，注销并重新进入 GNOME。在普通文本框切到 WowType 中文输入，长按空格右侧的「右 Alt」约 450 毫秒，看到红色麦克风提示后说话，松手提交。短按可选中修饰键，英文长按也按修饰键处理。

适用于 TB710FU 的 GNOME Shell 50 桌面和支持离线语音的 WowType / Fcitx5。首次缺少模型时，使用本机 WowType 自带的下载与校验工具，从其配置的上游下载约 103 MB，展开约 136 MB。已有模型可直接复用。识别在平板本地进行。实际听写需要在系统声音设置中选择可用的输入设备。

此项按当前桌面用户的 XDG 目录安装键盘快捷扩展 v22。系统预装扩展继续保留。安装程序从设备树识别机型，可以使用不同的分区布局、内核日期和启动器。运行期间无需管理员权限。语音开关和快捷键会设为启用及 Alt_R。

从条目目录执行下列命令。助手默认执行安装。

```sh
bash script.sh check
bash script.sh apply
bash script.sh rollback
```

首次安装把当前用户的原键盘文件、扩展启用状态和两项语音设置记录在 `$XDG_STATE_HOME/tb710fu/osk-right-alt-voice`（默认 `~/.local/state/tb710fu/osk-right-alt-voice`）。重复安装沿用首次记录。回退后重新登录。原先使用系统键盘的账号将重新使用系统版本。已经预装相同 v22 的账号会恢复到原有 v22。回退保留共享离线模型，安装后另行更新的键盘文件会提示核对。

在一台 TB710FU 的独立 GNOME 会话中，模拟触摸右 Alt，三句普通话合成语音均由 WowType 离线识别并完整进入 GTK 输入框。另一次使用平板扬声器播放「平板电脑的语音输入已经打开了」，由内置麦克风拾音，上屏文字与原句一致。短按和英文长按均未进入监听。
