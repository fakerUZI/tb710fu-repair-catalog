# 拔下磁吸键盘后首次挂起失败

适用于 TB710FU Ubuntu 和提供键盘连接、霍尔及供电状态的联想 Pogo 驱动。实机在开机后首次挂起时收到 GPIO137 上残留的下降沿，导致系统返回 EBUSY。修复在驱动确认键盘已拔下且断电时临时关闭键盘唤醒，恢复后还原原先的唤醒设置。连接键盘时保留原有唤醒行为。

在修复助手详情页下载并运行，下一次挂起即生效。实机使用内核 7.2.6-tb710fu-20261124，安装后连续五轮通过 RTC 唤醒并恢复。

如需撤销，退出助手后在终端以桌面用户运行以下命令，再打开本条目并点击运行。

```sh
TB710FU_FIX_ACTION=rollback tb710fu-repair-assistant
```
