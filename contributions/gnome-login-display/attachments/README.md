# TB710FU GNOME 登录与解锁黑屏恢复

适用于开机或注销重登后，GNOME 已进入会话，但 60 Hz 或 144 Hz 内屏仍显示上一帧、假锁屏或只有背光；也适用于 60 Hz 内屏首次解锁后画面没有恢复的现象。

在修复助手运行本项，保存工作后注销并重新登录。在本机 GNOME Wayland 会话就绪且解锁时，脚本确认内屏为唯一输出，再通过 Mutter 的显示电源接口短暂关屏和恢复。登录时只处理 60 Hz 和 144 Hz，每次登录最多尝试一次。正常锁屏解锁时只处理 60 Hz，等锁屏状态退出后恢复一次。外接屏幕或其他模式会跳过，桌面刷新率设置不变。

脚本以当前用户权限安装，可直接更新上一版 144 Hz 登录恢复。GNOME 或内核已经卡死且不再响应时，本项无法触发。可用 `journalctl --user -u tb710fu-login-display.service -b` 查看登录和解锁各自的恢复记录。

使用 `TB710FU_FIX_ACTION=check` 只读检查当前显示模式。使用 `TB710FU_FIX_ACTION=rollback` 停用并删除本项用户级文件。
