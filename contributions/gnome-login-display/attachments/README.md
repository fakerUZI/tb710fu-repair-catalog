# TB710FU GNOME 登录显示恢复

适用于开机或注销重登后，GNOME 已进入会话，但 144 Hz 内屏仍显示上一帧、假锁屏或只有背光。以往的实机记录显示，重新熄屏和亮屏能在部分情况下恢复画面。曾试过让 GDM 也用 144 Hz，仍出现黑屏。

在修复助手运行本项，保存工作后注销并重新登录。系统会在本机 GNOME Wayland 会话就绪且解锁时，确认内置屏为唯一输出并在运行原生 144 Hz，然后通过 Mutter 的显示电源接口短暂关屏再恢复。画面可短暂熄灭一次。每次登录最多尝试一次。外接屏幕、120 Hz 或其他模式会跳过，桌面刷新率选择保持原有值。

脚本以当前用户权限安装，只在下次图形登录时生效。GNOME 或内核已经卡死且不再响应时，本项无法触发。已知日志和操作结果可用 `journalctl --user -u tb710fu-login-display.service -b` 查看。其他用户平板上的黑屏现场和自动重启仍待验证。

使用 `TB710FU_FIX_ACTION=check` 只读检查当前显示模式。使用 `TB710FU_FIX_ACTION=rollback` 停用并删除本项用户级文件。
