# 恢复当前 Wi-Fi 的高速协商

适用于 TB710FU 上安装了已识别版本的 Wi-Fi 兼容服务的 Ubuntu 26.04。该服务会设置 `disable_vht=1`，可能使支持 Wi-Fi 6 的路由器与平板只能以 Wi-Fi 4 连接。请从平板本地先连接目标网络，再在修复助手单独应用，最后重新连接该网络。旧的兼容行为继续用于其他网络。

安装脚本只查询当前网络名和协商限制。它在本机兼容脚本中记录一个网络的例外，支持只读检查、应用和回退。更换例外时，先回退，再连接新网络并应用。

如果重连失败或变得不稳定，在本地执行回退后重新连接。命令行回退可在解包目录执行 `sudo env TB710FU_FIX_ACTION=rollback bash script.sh`。如果当前兼容脚本或服务属于不同版本，脚本会保留现场并提示检查。

在一台 Ubuntu 26.04.1、`7.2.6-tb710fu-20261118` 平板上，按网络解除限制后从 Wi-Fi 4／40 MHz 恢复到 Wi-Fi 6／160 MHz。Mac 与平板同走 Wi-Fi，短时局域网测速从下载 167／上传 171 Mbps 提升到 354／400 Mbps。5 分钟测试中持续下载平均 369 Mbps、持续上传平均 427 Mbps，双向满载平均下载 329／上传 53 Mbps，300 次探测零丢包，空闲后下载恢复到 370 Mbps。双向满载探测往返延迟 p95 为 164 ms，空闲时为 14 ms。

发布版安装脚本已在同一台平板上完成检查、应用、回退、再次应用和重连，重连后实测为 Wi-Fi 6／160 MHz。macOS 和 Ubuntu ARM64 各通过 8 项隔离测试，覆盖旧文件保护、单网络匹配及服务重启失败恢复。
