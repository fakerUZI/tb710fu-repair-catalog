# 磁吸键盘背折与屏幕键盘

适用于 TB710FU 的 Ubuntu GNOME 50 桌面。磁吸键盘已能打字并上报姿态时，展开后用手指点输入框，屏幕键盘保持收起。翻到背面后点输入框，屏幕键盘自动弹出。另接可打字的 USB 或蓝牙键盘时，桌面继续屏蔽自动弹出。顶栏按钮在两种姿态下都能手动开关。

在修复助手刷新目录，打开「磁吸键盘背折与屏幕键盘」，从详情页安装或更新。旧正式版、两版背折测试版均可直接升级，已装测试版的用户也请运行一次正式条目，以便修复助手记录安装状态。需要管理员权限。保存工作后注销并重新登录 Ubuntu 桌面。

首次安装或重新吸附时，桌面按键盘可打字处理，直到驱动发出姿态事件。验证时保持磁吸连接，背折、展开各一次，每个姿态停两秒，再用手指点「设置」的搜索框。

修复写入 GNOME 输入策略和顶栏扩展，并为联想磁吸键盘安装 udev 规则、systemd 服务和姿态读取器。服务仅向桌面发布启用或禁用状态，拔下键盘后自动停止。回退请在正式条目详情页执行，随后注销并重新登录。回退会移除姿态服务、规则和本条目的全部桌面补丁，包括旧正式版的磁吸识别补丁。
