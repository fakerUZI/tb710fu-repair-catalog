# DroidLoom 扬声器破音缓解

适用 Ubuntu 26.04 系列（原实测为 26.04.1）、ARM64、`7.2.6-tb710fu-snap1` 和 WirePlumber 0.5。安装前要求现有扬声器与内置麦克风节点、用户 WirePlumber 会话可用。需要 Python 3、systemctl、pactl 和 wireplumber；不要 sudo。

保持投稿原有的音频规则不变：对指定扬声器/麦克风节点调整图时钟优先级，为扬声器请求 256 帧周期和 256 帧 headroom。实际硬件可以协商成其他大小，原实测为 480 帧周期、3840 帧缓冲，不能把请求参数当作实际采纳值。参数含义参见 [WirePlumber 官方 ALSA 配置](https://pipewire.pages.freedesktop.org/wireplumber/daemon/configuration/alsa.html)；这些参数本身不保证所有音源、同时录音或长期运行稳定。

## 动作

- 命令行默认 `TB710FU_FIX_ACTION=check`，只读检查，不写配置、改变音量或重启服务。
- `apply` 保存首次运行前的原配置和权限到用户私有状态目录，再安装规则并重连 WirePlumber。重连前临时静音，重连后恢复每个通道的绝对音量及原静音状态。原音量无法读取时中止，不修改音频配置。当前修复助手默认显式传入 apply，点击运行前应阅读风险。
- 重复安装同一版本不会重复重启音频。后来被用户修改的配置不会自动覆盖。
- `rollback` 恢复首次安装前的配置。初次运行前不存在本条文件时才删除它；原来已有同名同内容规则时会恢复它，并保留其权限。没有本包记录时，不会猜测删除手工配置。其他规则完全不在本条目的管理范围。

配置位于 `~/.config/wireplumber/wireplumber.conf.d/99-tb710fu-android-audio.conf`，遵循 XDG_CONFIG_HOME。状态位于 `~/.local/state/tb710fu-android-audio`，遵循 XDG_STATE_HOME；目录 700，记录 600，只留本机，不上传。

回退不要求麦克风节点仍存在，也不要求旧内核/发行版仍匹配。音频会话已停止时只恢复配置，不擅自启动服务；无法读取旧音量时不会猜测音量。重启、节点等待或音量恢复发生可捕获故障时，尝试恢复本次操作前配置与音量；恢复失败会保留记录并报错，需人工检查。断电、强制结束或存储故障不保证恢复，重连后仍应检查媒体音量。

## 验证边界

原音频参数有投稿者的播放、安卓容器重启后播放和短期错误计数观察证据，未完成最新规则的整机重启、同时录音和长期稳定性验证。本轮保持规则内容逐字节一致，对新安装器运行 28 项隔离回归测试（macOS 与 ARM64 Linux），只使用临时文件和模拟音频命令，未在平板上执行本轮 apply/rollback。四个实体扬声器的其他静音问题不在此规则的已验证修复范围。
