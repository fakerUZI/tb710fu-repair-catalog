# Droidloom 安卓窗口和手势导航（第 13 版）

适用于 Lenovo TB710FU、Ubuntu 26.04 ARM64、GNOME Shell 50 Wayland 和已安装的 Droidloom。已核对内核 `7.2.6-tb710fu-20261118` 上运行的第 13 版扩展。

- 安卓主窗口默认最大化，焦点窗口显示外部阴影，顶栏窗口菜单提供还原、全屏、最小化和关闭。
- 底部白条可轻点或上滑最小化当前安卓窗口，上滑停留后可打开最近任务。
- 从左或右边缘向内滑显示返回箭头，松手发送返回键，滑回边缘取消。内置屏幕键盘打开时，暂停冲突手势。

## 使用和回退

可直接在修复助手应用安卓窗口与手势条目。手动运行时，进入本条目目录执行：

```bash
bash script.sh
TB710FU_FIX_ACTION=apply bash script.sh
TB710FU_FIX_ACTION=rollback bash script.sh
```

第一条为只读检查。应用会切换当前用户的安卓窗口扩展选择，旧版第 10 版目录仍用于原有设置和本机恢复。新版本的回退状态保存在 `$XDG_STATE_HOME/tb710fu-droidloom-window-navigation-v13/`，未设定时使用 `~/.local/state/`。如果第 13 版文件之后被手动改动，脚本会保留该改动并停止自动回退。应用后保存工作，注销再登录 GNOME。

## 验证

源码、样式和元数据与 TB710FU 上正在使用的第 13 版一致。已在平板比对当前组件，应用和回退在隔离目录验证。通过修复助手安装后重新登录的完整实机流程仍待验证。
