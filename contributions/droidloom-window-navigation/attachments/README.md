# Droidloom 安卓窗口和手势导航

适用于 Lenovo TB710FU、Ubuntu 26.04 ARM64、GNOME Shell 50 Wayland 和已安装的 Droidloom。已验证 Droidloom release 42 和内核 `7.2.6-tb710fu-20261118`。

新打开的安卓主窗口默认最大化到 GNOME 工作区。顶栏「安卓」提供还原、全屏、最小化、关闭、调整大小。拖动调整时先显示预览，松手后才提交实际尺寸。新窗口规则通过 Wayland 客户端的 Droidloom 进程身份识别安卓窗口，现有窗口和手动还原状态保留。

全屏和窗口模式都显示底部白条。短上滑或轻点白条会最小化当前安卓窗口，长上滑停留后松开会打开最近的安卓窗口。从左右窗口边缘向内滑时显示返回箭头，松手后向 Android 发送返回键，滑回边缘可取消。GNOME 屏幕键盘弹出期间暂停导航，收起后恢复。

## 应用与回退

在 GNOME 桌面以普通用户通过修复助手应用。也可进入解包目录执行同一个 Bash 入口。

```sh
bash script.sh
TB710FU_FIX_ACTION=apply bash script.sh
TB710FU_FIX_ACTION=rollback bash script.sh
```

默认动作是只读检查。应用安装或复用与附件完全一致的用户扩展，并更新该用户的扩展启用选择。当前会话尚未识别新扩展时，保存工作后注销并重新登录 GNOME。等待登录期间旧安卓控件可能已停用。脚本无需重启容器。旧版扩展文件、Droidloom 和 Android 数据随原安装保留。回退恢复此前安卓扩展选择，移除本条目创建且内容一致的目录。快照在 `$XDG_STATE_HOME/tb710fu-droidloom-window-navigation/`，未设 XDG 路径时保存到 `~/.local/state/`。在别处另有修改的同名扩展需要手动核对。

## 验证

平板 GNOME 50.1 已加载与附件相同的扩展。安卓设置和文件的新窗口实测以 GNOME 最大化打开。已验证手动还原后切换焦点不自动最大化，以及普通 GNOME 应用的窗口状态。已验证全屏和窗口模式下的短上滑最小化、最近任务、键盘避让，以及窗口模式通过 Linux 触摸输入链路的短上滑。此前平板验证以开发测试方式加载扩展。投稿脚本的应用和回退在隔离环境验证，实机只运行只读检查，修复助手的首次安装和重新登录待验。
