# TB710FU 锁屏人脸解锁

在修复助手点击「更新仓库」，安装「锁屏人脸解锁」。从应用菜单打开「人脸解锁」，依次选择「预览并录入」和「开始录入」。已经集成该界面的 GNOME 设置也可从「隐私与安全 → 锁屏」进入。录入成功后启用。锁屏后打开密码页，正视前摄。可随时停用，或删除本账号的人脸资料。

需要 Ubuntu 的 GNOME Wayland 与 GDM，以及已能出画面的 TB710FU 前摄。安装会用现有前摄和附件模型实测取帧。开始安装前关闭正在使用相机的应用。缺少用户态依赖时由 APT 补齐。两个识别模型共约 39 MB，随助手附件下载。识别、录入和特征存储均在平板本地进行。安装保留原有录入和启用状态。首次安装由用户主动录入和启用，首次登录、SSH、sudo 仍使用原认证方式。

这项功能采用现有正脸匹配方案，未实现专门的活体检测。需要更高安全性时可在应用中停用并使用锁屏密码。

`TB710FU_FIX_ACTION=check` 只检查依赖、GDM 入口和前摄。安装后可通过「人脸解锁 → 停用」撤销 GDM 人脸认证。修复助手以 `TB710FU_FIX_ACTION=rollback` 运行可还原本次修改的安装文件。卸下认证组件时会先移除其 GDM 规则，回退保留本机人脸资料。

模型对应 OpenCV Zoo 提交 [48b10fa](https://github.com/opencv/opencv_zoo/tree/48b10fa505aeb51fbd127fc60a5c660040e823b7/models)。YuNet 与 SFace 许可证随附件提供。SFace 原模型分五段配送，安装时校验重组后的模型。
