# TB710FU 后摄补光灯启动修复

适用于已经安装相机和手电筒组件的 TB710FU Ubuntu ARM64，内核为 `7.2.6-tb710fu-20261117` 或 `7.2.6-tb710fu-20261118`。启动菜单更换或不同存储容量的平板出现「当前 boot 不匹配」「当前 GPT 布局不匹配」时，可在修复助手应用此条。微距启动会调用同一项补光灯检查。

在修复助手点击执行，默认 `apply`，需要管理员权限。命令行可用 `TB710FU_FIX_ACTION=check` 检查，或设为 `rollback` 恢复原运行脚本。成功应用后重新打开相机或手电筒即可使用。若此前微距服务启动失败，下次正常启动会重新检查，也可在关闭相机后手动启动 `tb710fu-macro-camera.service`。

脚本更换补光灯启动检查并启动相关服务。检查使用运行中的 TB710FU 设备树、PM8550 控制器和输出通道，核对内核配置、模块 ABI、附件哈希及电流和点亮时限。整盘分区布局、分区固件哈希和整张启动镜像不参与点灯检查。原组件保存在 `/var/lib/tb710fu-flash-portable/original.py`，只保留在本机。安装和回退均无需重启；回退后，下次启动服务使用旧脚本。

在 TB710FU 的 20261118 内核上实测通过检查、应用、回退和再次应用。从卸载闪光灯模块的状态重新加载，确认一级补光亮度回读为 32、故障标志为空、关闭后读数为 0。20261117 和其他存储容量未做实机测试。
